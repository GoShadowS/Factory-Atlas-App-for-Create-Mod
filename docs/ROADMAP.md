# Дорожная карта развития (`ROADMAP`)

## Версия v1.0 (реализовано в кодовой базе)
- Полностью пустой старт новых проектов (`nodes: []`, `edges: []`, `customResources: []`, `customMachines: []`, `customRecipes: []`) и ручное создание ресурсов, машин и рецептов.
- Детерминированный поиск 3D-моделей и текстур по локальному справочному индексу (`visualMatcher.ts`, поддержка RU/EN `lang`, выбор пользователя при неоднозначности, сохранение назначений в `.factoryatlas`).
- Реальный 3D-рендер статических моделей Minecraft JSON (`elements`, `parent`, `#texture`, `blockstates` `variants`/`multipart`, повороты элементов, LRU-кэш) + честная классификация `2d-item-generated`, `unsupported-obj`, `procedural-or-blockentity`.
- 3D-просмотрщик Create `.nbt` (`StructureTemplate`) с орбитальным вращением, зумом, срезами Y, палитрой, статусом 3D-модели каждого блока и экспортом BOM CSV.
- Инкрементальный расчётный движок графа с формулами Create `6.0.11`, разделением `предм./мин` и `мБ/мин`, обнаружением циклов (Тарьян SCC), проверкой дефицита/узких мест, вероятностных выходов и SU.
- Защищённый импорт `.jar` / `.zip` / `.json` только по явному действию и подтверждению пользователя.
- Версионируемый `.factoryatlas` v2 (+ миграция v1 -> v2), автосохранение, экспорт SVG / PNG / CSV.
- Конфигурация Tauri v2 (`src-tauri/src/lib.rs`) с разделением данных **Installed** (`%APPDATA%`) и **Portable** (`./data/`) + workflow `.github/workflows/windows-installer.yml` (требует сборки и проверки на Windows / `windows-latest`).

## Планы v1.1 — v1.3
- **v1.1 (Удобство и производительность):**
  - Всплывающие подсказки с декомпозицией формулы тиков прямо по наведению на узел на холсте.
  - Перенос тяжёлого разбора больших модпаков (`.jar` > 20 МБ) в Web Worker.
  - Авто-трассировка ортогональных рёбер без наложения на карточки узлов.
- **v1.2 (Расширение форматов 3D и схем):**
  - Поддержка Wavefront OBJ (`neoforge:obj` + `.mtl`) в 3D-вьюере.
  - Чтение `.schem` (Sponge) и `.litematic` (Litematica) в режиме строгого только-чтения.
  - Поддержка тегов рецептов (`#c:plates/iron`, `#minecraft:planks`).
- **v1.3 (Кроссплатформенная сборка и WebGL):**
  - Нативные сборки для **Linux (AppImage / .deb)** и **macOS (Universal .dmg)** через Tauri v2.
  - Аппаратный WebGL-рендерер для сверхкрупных `.nbt` схем (> 10 000 блоков).
