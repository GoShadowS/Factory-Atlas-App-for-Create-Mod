# Руководство по моделям и замене текстур (`ASSET-REPLACEMENT`)

Factory Atlas использует стабильные строковые ID вида `<namespace>:<id>` (например, `create:cogwheel`, `create:mechanical_press`, `electroenergetics:transformer`) и поддержку как **2D PNG текстур**, так и **статических 3D JSON моделей Minecraft**.

---

## 1. Автоподбор при создании ресурса или машины

В окне **«Создать ресурс / машину»** введите название (на русском или английском), ID (`create:cogwheel`) или путь модели и нажмите **«Найти»**. Поиск (`src/lib/assets/visualMatcher.ts`) выполняется в строгом порядке:
1. Точный namespaced ID (`create:cogwheel`).
2. Точный путь модели, текстуры или blockstate.
3. Нормализованный ID / имя файла (`Brass Ingot` -> `brass_ingot`).
4. Точное совпадение из `lang` (`ru_ru.json` / `en_us.json`).
5. Частичное совпадение (если найдено несколько кандидатов — отображаются карточки с миниатюрами для выбора пользователем).

Назначенный визуал можно изменить, загрузить вручную или отключить (вернувшись к нейтральной SVG-заглушке) прямо из **Инспектора** — все настройки сохраняются в файле `.factoryatlas`.

---

## 2. Загрузка собственных PNG и 3D JSON моделей

1. **Через окно создания / инспектор узла:** кнопки **«Свой .png»**, **«Своя 3D .json»** и **«Откл. визуал (заглушка)»**.
2. **Через менеджер текстур (кнопка «Текстуры» в шапке):** замена 2D-спрайта для любого ресурса/машины проекта.
3. **На диске в `assets-overrides/`:**
   - PNG-оверрайд: `assets-overrides/<namespace>__<id>.png` или `assets-overrides/<namespace>/<id>.png`.
   - 3D JSON-оверрайд модели (для веб-предпросмотра): `assets-overrides/models/<namespace>/models/<subpath>.json`.

---

## 3. Поддерживаемые и неподдерживаемые 3D форматы

- **Поддерживается:** статический Minecraft JSON (`elements`, `from`/`to`, `uv`, повороты элементов, `rotation.x`/`y` в `blockstates`, наследование `parent`, `#texture` переменные, `variants` и `multipart`, базовые примитивы `cube_all`, `cube_bottom_top`, `cube_column`, `orientable`, `slab`, `carpet`).
- **Отображается честно как 2D:** предметы с `parent: "minecraft:item/generated"` / `"item/handheld"` (показывается пометка *«Только 2D-иконка (не 3D)»*).
- **Не поддерживается в 3D (помечается явно):** модели `neoforge:obj` и процедурные/динамические BlockEntity-рендеры без `elements`.
- **Анимированные жидкости (`16×512`):** вертикальные спрайт-ленты автоматически обрезаются до первого кадра `0, 0`.
